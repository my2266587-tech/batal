# מערכת בט״ל

מערכת ניהול בעברית (RTL) למטופלים, פגישות וכספים — מבוססת Next.js 14 + Supabase.

## התקנה והרצה

### 1. התקנת תלויות
```bash
npm install
```

### 2. הגדרת Supabase
1. צור פרויקט חדש ב-[supabase.com](https://supabase.com).
2. עבור ל-**SQL Editor**, פתח את `schema.sql` שבתיקייה והדבק את התוכן. הרץ.
3. (אופציונלי — להעלאת קבצים) ב-**Storage**, צור Bucket ציבורי בשם `documents`.
4. ב-**Project Settings → API** העתק את:
   - `Project URL`
   - `anon public key`

### 3. משתני סביבה
צור קובץ `.env.local` בשורש הפרויקט:
```
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

### 4. הרצה
המערכת מוגדרת לרוץ על **פורט 3001** (כדי לא להתנגש בפרויקט אחר שרץ על 3000).

```bash
npm run dev
```
פתח בדפדפן: <http://localhost:3001>

לבנייה לפרודקשן:
```bash
npm run build
npm start
```
(`npm start` רץ גם הוא על פורט 3001.)

### החלפת פורט
הפורט מוגדר בקובץ `package.json` תחת `scripts`. להרצה על פורט אחר:
```bash
npx next dev -p 3002
```

## מודולים

- **דשבורד** — סך שעות וסכומים לחודש הנוכחי, סיכום לפי מטופל, משימות אחרונות.
- **מטופלים** — שם, טלפון, אימייל, סטטוס, הערות, תאריך יצירה.
- **משימות ופגישות** — טופס מלא לפי המפרט, סינון לפי מטופל / תאריך / סוג / סטטוס, סיכומים אוטומטיים.
- **קופה** — תאריך, סכום, עבור, הערות.

## ייבוא Excel / CSV (רב-שימושי)

בעמוד **ייבוא נתונים** בסרגל הניווט. תחילה בוחרים **יעד**: `מטופלים`, `משימות / פגישות` או `קופה`. לכל יעד יש תבנית להורדה ומבנה עמודות שונה.

### זיהוי עמודות אוטומטי
כותרות נסרקות בעצמת התעלמות מרווחים, גרשיים וגדול/קטן. עבור שם המטופל מזוהים: `שם מטופל`, `שם המטופל`, `מטופל`, `שם מלא`, `שם`. למחיר לשעה: `מחיר לשעה`, `תעריף לשעה`, `תעריף`. וכן הלאה. בעת הצגת ה-Preview רואים אילו עמודות מופו ואילו לא.

### זיהוי מטופל קיים
- ההתאמה היא לפי **שם** (case-insensitive, ללא רווחים מיותרים).
- אם נמצא מטופל יחיד באותו שם — הוא יקושר אוטומטית, גם בלי טלפון בקובץ.
- אם מספר מטופלים חולקים את אותו שם — נדרשת עמודת טלפון בקובץ; אחרת השורה תסומן כשגיאה ולא תיובא.
- אם לא קיים — ייווצר מטופל חדש עם הפרטים בשורה.

### זרימת ייבוא
1. בחירת קובץ → הצגת **Preview**: כמה שורות, כמה משימות תקינות, כמה מטופלים חדשים, כמה שגיאות.
2. שורות עם שגיאה מוצגות במפורש ולא ייובאו.
3. אישור → המערכת יוצרת מטופלים חדשים שאינם קיימים, מעדכנת מטופלים קיימים בשדות שסופקו, ויוצרת רשומות `tasks`.

## חישוב אוטומטי של תשלום לפי תעריף מטופל

- בדף **מטופלים** ניתן לקבוע לכל מטופל: סוג טיפול, מחיר לשעה, מחיר לשעה אחרי הנחה.
- בדף **משימות**: כשבוחרים מטופל מוצג מתחת לשדה השעות התעריף שלו. בעת שינוי מטופל או משך שעות, הסכומים `סה"כ לפני הנחה` ו-`סה"כ אחרי הנחה` מתחשבים אוטומטית.
- אם למטופל אין `מחיר לשעה אחרי הנחה`, החישוב משתמש במחיר הרגיל.
- ניתן לדרוס ידנית את הסכומים — השדות לעריכה ופתוחים.

## עדכון סכמה (להתקנות קיימות)

אם כבר הרצת את `schema.sql` הישן, יש להריץ ב-SQL Editor של Supabase:
```sql
alter table patients add column if not exists treatment_type text;
alter table patients add column if not exists hourly_rate numeric(10,2);
alter table patients add column if not exists hourly_rate_discounted numeric(10,2);
```
(הקטעים האלה גם נמצאים בתחתית `schema.sql` ובטוחים להרצה חוזרת.)

## הערות

- כל החישובים (סיכומי שעות, סכומים, נסיעות) מתבצעים בזמן אמת מהנתונים בטבלאות.
- תאריך עברי הוא שדה טקסט — מאפשר הזנה ידנית ללא תלות בספריות חיצוניות.
- ה-RLS פתוח כברירת מחדל לפיתוח מהיר. בייצור יש להוסיף Auth ולהדק מדיניות.

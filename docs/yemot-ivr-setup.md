# יצירת משימה דרך הטלפון — ימות המשיח (Yemot Hamashiach)

יצירת משימה במערכת בט"ל באמצעות **הקלטה אחת** בקו ימות המשיח. המשתמשת אומרת
במשפט אחד את **שם המטופלת**, **משך השעות** ו**הגדרת המשימה**. לאחר אישור,
השרת מפרק את התמלול לשדות ויוצר משימה ישירות בטבלת `tasks` הקיימת.

## הזרימה (מנוהלת ע"י שלוחת API אחת)

1. **פתיחה** — "להקלטת משימה חדשה הקישי 1".
2. **הקלטה אחת** — "אמרי במשפט אחד את שם המטופלת משך השעות והגדרת המשימה ולסיום הקישי סולמית".
3. **אישור** — השמעת ההקלטה + "לשמירה הקישי 1 להקלטה מחדש הקישי 2 לביטול הקישי 3".
4. בהקשה **1** נוצרת המשימה ב-`tasks`. ניתוק לפני אישור אינו יוצר משימה.

מצב השיחה נשמר זמנית ב-`ivr_sessions`; כפילויות נמנעות לפי מזהה השיחה
(`ApiCallId`).

הכתובת (Endpoint):
```
https://<הדומיין-שלך>/api/ivr/yemot?token=<YEMOT_IVR_TOKEN>
```

## פירוק התמלול לשדות (טבלת `tasks` הקיימת)

| נאמר בשיחה | עמודה ב-`tasks` |
|------------|------------------|
| שם המטופלת | `patient_id` (התאמה לפי שם; אם לא זוהתה — ריק) |
| משך שעות | `hours` (עשרוני; אם לא זוהה — ריק, לא חוסם) |
| הגדרת המשימה | `task_definition` |
| מקור | `source` = "phone" |
| מספר מתקשרת | `caller_phone` |
| נתיב ההקלטה | `recording_url` |
| תמלול מלא | `transcription` |
| מזהה שיחה (כפילויות) | `call_external_id` |
| סטטוס | `status` = "פתוח" |

- **זיהוי מטופלת** מתבצע לפי השם שנאמר (התאמה ל-`full_name`). אם לא נמצאה
  התאמה — המשימה נוצרת **ללא שיוך**, והמשפט שנאמר נשמר ב-`other_details`
  ("מהטלפון - לא זוהתה מטופלת. נאמר: ...") לעריכה ושיוך ידני.
- **משך השעות** מזוהה ממילים/ספרות: "שעה", "שעתיים", "שעה וחצי", "חצי שעה",
  "רבע שעה", "שלוש שעות וחצי", "2 שעות", "90 דקות" וכו'. אם לא זוהה — נשמר ריק.

## הגדרת השלוחה בימות המשיח

1. ניהול המערכת → **ניהול שלוחות** → שלוחה חדשה (למשל `5`).
2. סוג שלוחה: **שלוחת API**.
3. כתובת ה-API (כולל ה-`token`):
   ```
   https://<הדומיין-שלך>/api/ivr/yemot?token=<YEMOT_IVR_TOKEN>
   ```
4. שיטה: `GET` או `POST` — שתיהן נתמכות.
5. ודאי שהעברת משתני שיחה פעילה (השרת מזהה את ערכי ההקלטה/ההקשה בחזרה).

### תמלול (חשוב)
פירוק המשפט לשדות מסתמך על **תמלול** שמגיע מימות. אם בחבילת ימות שלך מופעל
זיהוי דיבור / תמלול להקלטה, השרת יקרא אותו (מתוך פרמטרים כמו `transcription`,
`transcript`, `ApiTranscript`, או `<שם-משתנה-ההקלטה>_transcription`). אם אין
תמלול — המשימה עדיין נוצרת עם ההקלטה (`recording_url`) ו-placeholder, לטיפול ידני.

## משתני סביבה ב-Vercel

| משתנה | תיאור |
|-------|-------|
| `YEMOT_IVR_TOKEN` | **חובה** (fail-closed). סוד שימות שולח בפרמטר `token`. חסר → 503; שגוי → 401. |
| `SUPABASE_URL` / `SUPABASE_ANON_KEY` | אופציונלי; נופלים חזרה ל-`NEXT_PUBLIC_*`. anon בלבד — לא service_role. |

## בדיקת שיחה מלאה (סימולציה)

```bash
BASE="http://localhost:3001/api/ivr/yemot?token=LOCAL_SECRET"
CID="testcall-001"

# 1) פתיחה → בקשת "הקישי 1"
curl -s "$BASE&ApiCallId=$CID&ApiPhone=0501234567"
# 2) הקשה 1 → בקשת הקלטה
curl -s "$BASE&ApiCallId=$CID&v1_1=1"
# 3) ההקלטה + התמלול נשלחים → מסך אישור
curl -s "$BASE&ApiCallId=$CID&v2_1=rec/call.wav&transcription=רבקה%20שעה%20וחצי%20פגישת%20מעקב"
# 4) אישור ושמירה → "המשימה נשמרה בהצלחה"
curl -s "$BASE&ApiCallId=$CID&v3_1=1"
```

לאחר שלב 4 נוצרת שורה אחת ב-`tasks` עם `source='phone'`, מופיעה בניהול
המשימות עם התג "מהטלפון", וניתנת לעריכה מלאה. הרצה חוזרת של שלב 4 עם אותו
`ApiCallId` לא תיצור כפילות.

> שמות המשתנים (`v<step>_<attempt>`) נקבעים ע"י השרת ומוחזרים בתוך פקודות
> ה-`read`. בשיחה אמיתית ימות מטפל בהם אוטומטית.
